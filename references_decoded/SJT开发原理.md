# 情境判断测验（SJT）开发原理与流程

本文件摘录自《情境判断测验：基本原理与测验开发》课程讲义（人事与组织心理，2024），供编制题目时参考规范。

---

## 一、SJT概述

**定义**：情境判断测验（Situational Judgment Test, SJT）是一种有效的人事选拔工具，为个体呈现工作相关的典型情境及该情境下可能的行为反应，要求作答者根据指导语进行选择或评价（Weekley & Ployhart, 2006）。

**属性**：SJT属于低保真度情境模拟（low-fidelity simulation），介于人格测验与情境面试之间。

**优势**：

- 易接受：较好的实践指向性，较高的表面效度
- 效果好：较高的预测效度，能更好地预测未来工作绩效
- 独特性：测量与工作相关的知识和技能（传统成就测验无法测到）
- 便捷性：施测操作简便高效，支持大规模群体施测
- 公平性：更高的公平性，降低负面影响（群体差异）
- 克服赞许性：形式上更能克服自陈测验带来的社会赞许性偏差

## 二、SJT理论基础

| 理论           | 核心观点                                                                      |
| -------------- | ----------------------------------------------------------------------------- |
| 行为一致性理论 | SJT基于实际工作情境中的行为反应，遵循行为一致性原则（Motowidlo et al., 1990） |
| 实践智力理论   | SJT测量不同于一般智力的实践智力或工作知识（Sternberg & Wagner, 1993）         |
| 隐性特质理论   | 个体在人格特质上的差别影响对行为有效性的判断（Motowidlo et al., 2006）        |
| 特质激活理论   | 人格特质需借助与特质相关的情境才能被激活和体现（Tett & Guterman, 2000）       |

**关键含义**：情境本身不应暗示正确答案（避免"强情境"效应），应构造弱到中度强度的情境以激活特质差异。

## 三、SJT开发四步流程

### Step 1：编制情境

**两种取向**：

1. **关键事件法（归纳/经验取向）**：

   - 确定目标岗位，明确岗位要求
   - 通过行为事件访谈（BEI）收集典型情境
   - 访谈对象：行业专家（SMEs）
   - 对典型情境分类汇总并命名维度
   - 优点：信息丰富，预测效度有保证；缺点：费时费力，构想效度成疑
2. **基于理论法（演绎/理论取向）**：

   - 事先确定潜在构念模型（如胜任特征模型）
   - 基于构念定义编写题目情境
   - 优点：目标明确，针对性强；缺点："构想-情境"关系缺乏理论指导

**推荐做法**：

1. 根据需要出题的胜任特征维度，确定需要出题的构念。查询 ``competence_dictionary.json``明确维度定义、高低分特征和相关行为。
2. 从 ``competence_SJT.json``中提取胜任特征对应的情景、任务和行为锚点，作为题目的参考。
3. 结合关键事件收集真实情境素材，关键信息包括行业特征、团队/部门特征、岗位特征、相关的业务动作等。
4. 从 ``extracted_templates.json``中读取成熟例题，将收集到的真实素材，适当改编，形成新的具体题目情境。

**参考资料**：

- 胜任特征词典：包含所有可能的胜任特征，用于确定需要出题的构念。
- extracted_templates.json：使用变量占位符替换行业、岗位、角色、利益相关者等参数，形成题目模板，占位符包括：

  - 人名 -> {{Name}}
  - 行业/公司类型 -> {{Industry}}
  - 团队/部门 -> {{Department}}
  - 具体岗位 -> {{Role}}
  - 具体的业务动作（如研发、销售） -> {{Business_Action}}
- competence_SJT.json：从成熟SJT题目中提取的胜任特征与SJT情境、行为选项的对应关系，包括：

  - "dimension": 胜任特征维度
  - "abstract_scenario": 题干的工作情境描述
  - "management_task": 主角在此情境下面临的核心任务
  - "behavioral_anchors": 选项的行为锚点，包括：
    - "best_practice": "最高分选项的底层逻辑（为什么好）",
    - "suboptimal_practice": "中间分选项的底层逻辑（合理在哪，缺失在哪）",
    - "worst_practice": "最低分选项的底层逻辑（典型的执行偏差或新手误区）"

**题干编写规范**：

- 描述一个完整的工作情境：背景+任务+挑战+利益相关者
- 约150-250字，真实可信，贴近实际工作场景
- **不应暗示正确答案**（弱情境）
- 情境结束以"面对这种情况，你会怎么做？"引出选项

### Step 2：编制行为选项

**核心要求**：

- 每道题4个选项，描述具体可观察的行为（而非态度或想法）
- **等社会赞许性**：选项间在社会赞许性上无明显优劣，避免作答者猜测
- 选项内容尽量简短，描述清晰
- 可允许个别选项有相似或冗余（体现细微差异）

**行为等级编制参考**（基于构念取向）：

1. 定义研究的胜任特征构念
2. 确定能使该特质最大体现的情境
3. 建构反应选项连续体，每个选项代表特质表现的不同水平
4. 专家评定情境和选项与所研究特质的相关性

### Step 3：确定指导语

| 类型                  | 形式             | 测量重点           | 效度特点                                       |
| --------------------- | ---------------- | ------------------ | ---------------------------------------------- |
| 知识导向（Should-Do） | "你应该怎么做？" | 最佳表现，推断能力 | 与认知能力测验相关更高；对人格测验递增效度更大 |
| 行为导向（Would-Do）  | "你会怎么做？"   | 典型表现，推断人格 | 与人格测验相关更高；对认知能力测验递增效度更大 |

**本技能默认使用行为导向指导语**："面对这种情况，你会怎么做？"（评估典型行为倾向）

### Step 4：开发计分键

**方法**：

1. **理性计分（专家法）**：由SME独立判断各选项分值，讨论达成一致
2. **实证计分**：根据试测结果，以效标水平决定各选项得分
3. **理论计分**：依据理论文献确定计分逻辑
4. **混合式**：综合理性+理论方法

**本技能采用理论计分**：基于胜任特征等级描述（A-E），将行为选项对应到维度的不同水平（0-3分），并撰写赋分原因。

## 四、计分规则

### 均匀赋分（本技能默认）

| 选项 | 分值 | 行为水平                        |
| ---- | ---- | ------------------------------- |
| A    | 0分  | 最弱水平（对应胜任特征等级D-E） |
| B    | 1分  | 较弱水平（对应胜任特征等级C-D） |
| C    | 2分  | 较强水平（对应胜任特征等级B-C） |
| D    | 3分  | 最强水平（对应胜任特征等级A-B） |

> 注：选项位置与分值对应固定（A=0, B=1, C=2, D=3），每道题均如此。

## 五、质量检验标准

题目编制完成后应检查：

1. **情境**：是否真实、具体？是否含有无关线索（暗示答案）？
2. **选项**：是否描述具体行为（非态度/想法）？4个选项是否等社会赞许性？
3. **区分度**：4个选项之间是否有清晰的行为水平差异？
4. **赋分**：是否严格依据维度定义确定分值？赋分说明是否准确解释了行为含义？
5. **格式**：是否符合输出模板要求？

## 六、SJT测量的构念异质性说明

SJT题目在item水平呈现构念异质性，即单道题可能同时激活多种特质。因此：

- 内部一致性系数（α）不适合作为信度指标，**推荐重测信度**
- 用于测量特定构念时，应严格按照"基于构念的开发方法"编制题目
- 每道题限定测量一个维度，避免混淆测量构念
