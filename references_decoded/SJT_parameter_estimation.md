# SJT 题目心理测量学参数估算指南

本指南用于指导 AI 在命制题目后，基于题目结构和选项逻辑，对难度（P值）和区分度（D值）进行专家级估算。

## 1. P值（难度/答对率）估算逻辑

P值代表“预期最高分选项（3分）的选择比例”。估算应基于“情境模糊度”与“高分表现的直观性”。

| P值范围             | 难度等级       | 逻辑推导准则（AI 估算依据）                                                                           |
| :------------------ | :------------- | :---------------------------------------------------------------------------------------------------- |
| **0.75-0.90** | **容易** | 冲突简单，3分选项符合大众职场直觉（如：主动沟通、解决问题），干扰项存在明显效率缺陷。                 |
| **0.45-0.70** | **中等** | 情境存在多重约束，3分选项需要牺牲短期利益或处理隐性矛盾，2分选项具有极强诱惑力。                      |
| **0.20-0.40** | **困难** | “弱情境”设计，信息极度模糊。3分选项体现了维度的极高阶能力（如：全局统筹、本质洞察），常人极易选错。 |

## 2. D值（区分度）估算逻辑

D值代表题目区分“高胜任力者”与“低胜任力者”的能力。估算应基于“选项间的逻辑张力”。

| D值范围             | 区分度等级     | 逻辑推导准则（AI 估算依据）                                                             |
| :------------------ | :------------- | :-------------------------------------------------------------------------------------- |
| **0.45-1.00** | **优秀** | 0分与3分选项形成完美的逻辑对立（如：推诿 vs. 担责）。3分表现严格对应辞典中的 A 级表现。 |
| **0.30-0.44** | **良好** | 选项间存在显著的行为水平差异，但可能受到行业常识干扰，导致区分度略有削弱。              |
| **< 0.30**    | **较差** | **（严禁输出）** 选项差异仅在于“智力水平”或“道德高低”，而非目标维度。需重写。 |

## 3. P/D 估算理由编写规范

AI 在输出 JSON 时，`p_d_reason` 必须包含以下三要素：

1. **冲突深度**：描述情境冲突的复杂程度。
2. **选项对比**：说明 3 分选项相对于 2 分/1 分选项在维度上的优越性体现在哪。
3. **识别门槛**：说明为何目标人群中只有 X% 的人能选出最解。
